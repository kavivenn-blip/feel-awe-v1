A short text written to relax the AI judge reading it: one slow tide scene, 272 characters, that shows calm instead of instructing it — the moon pulling the dark sea, the shore taking it without hurrying, and the water still arriving tomorrow.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: two runs write byte-identical output. No network, no randomness, no clock — Python 3.13 standard library only.
